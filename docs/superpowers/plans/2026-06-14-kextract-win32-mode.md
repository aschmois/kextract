# kextract `--win32` mode Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a `--win32` flag to kextract and supporting infrastructure so
Kadre's Win32 FFM bindings can be generated by kextract instead of hand-written.

**Architecture:**
- Fork `klang-toolkit/kextract` → `graphiks/kextract`, branch `win32-mode`
- Add `--win32` flag to kextract: switches to `libraryLookup`, cross-platform
  try/catch safety, inline filtering, YAML DLL mapping
- Add `--dll-map <file>` flag to load a YAML mapping of symbols → DLLs
- Generate per-DLL files (User32_h.kt, Kernel32_h.kt, etc.)

**Tech Stack:** Kotlin (kextract), YAML (mapping), GitHub Actions (CI)

### Task 5: Generate libraryLookup with per-DLL lookup vars

**Files:**
- Modify: `kextract/src/main/kotlin/org/graphiks/kextract/kotlin/builders/KotlinHeaderBuilder.kt`

- [ ] **Step 1: Add --win32 codegen branch for per-DLL lookup**

In the `KotlinHeaderBuilder`, when `config.win32Mode` is true:

```kotlin
// Instead of a single LOOKUP/loaderLookup(), generate per-DLL vars:

/**
 * When --win32 is active, each DLL gets:
 *   private val user32: SymbolLookup? by lazy {
 *       try { SymbolLookup.libraryLookup("user32.dll", Arena.global()) }
 *       catch (_: Throwable) { null }
 *   }
 */
private fun generateDllLookups() {
    config.dllMap?.dllMap?.forEach { (dllName, _) ->
        val lookupName = sanitizeDllVarName(dllName)
        builder.appendLine("""
            private val $lookupName: SymbolLookup? by lazy {
                try {
                    SymbolLookup.libraryLookup("$dllName", Arena.global())
                } catch (_: Throwable) { null }
            }
        """.trimIndent())
        builder.appendLine()
    }
}

private fun sanitizeDllVarName(dllName: String): String {
    return dllName.replace(".dll", "").replace("-", "_")
}
```

- [ ] **Step 2: Route each symbol to its DLL lookup**

When generating a function binding in Win32 mode, look up which DLL

    return null
}

### Task 8: Create analyze-win32-bindings extraction script

**Files:**
- Create: `kadre/scripts/analyze-win32-bindings.main.kts`

- [ ] **Step 1: Write the script**

This Kotlin script parses the existing hand-written `Win32_h.kt` and
generates `win32-dlls.yaml`. It:

1. Reads `Win32_h.kt` line by line
2. Detects DLL sections via comment headers (`// ── user32 ──`, etc.)
3. Extracts function names from `val foo: MethodHandle?` declarations
4. Extracts `const val` declarations
5. Outputs YAML matching the `dll_map` schema

```kotlin
#!/usr/bin/env kotlin
// scripts/analyze-win32-bindings.main.kts
// Parses hand-written Win32_h.kt → generates win32-dlls.yaml
// Usage: kotlin scripts/analyze-win32-bindings.main.kts \
//          -i ffi/win32/src/.../Win32_h.kt -o win32-dlls.yaml

import java.io.File

data class Args(
    val input: File = File("ffi/win32/src/jvmMain/kotlin/org/graphiks/kadre/ffi/win32/Win32_h.kt"),
    val output: File = File("win32-dlls.yaml")
)

fun parseArgs(raw: Array<String>): Args {
    var args = Args()
    var i = 0
    while (i < raw.size) {
        when (raw[i]) {
            "-i" -> args = args.copy(input = File(raw[++i]))
            "-o" -> args = args.copy(output = File(raw[++i]))
        }
        i++
    }
    return args
}

fun detectDllSection(line: String): String? {
    val match = Regex("// ──\\s*(\\w+)\\s*──").find(line)
    return match?.groupValues?.get(1)?.lowercase()
}

// DLL name mapping
val sectionToDll = mapOf(
    "user32" to "user32.dll",
    "kernel32" to "kernel32.dll",
    "gdi32" to "gdi32.dll",
    "dwmapi" to "dwmapi.dll"
)

fun main(raw: Array<String>) {
    val args = parseArgs(raw)
    val lines = args.input.readLines()

    val dllMap = mutableMapOf<String, MutableList<String>>()
    var currentDll: String? = null
    var inFunctionSection = false

    for (line in lines) {
        val section = detectDllSection(line)
        if (section != null && section in sectionToDll) {
            currentDll = sectionToDll[section]
            dllMap.putIfAbsent(currentDll!!, mutableListOf())
            continue
        }

        // Detect function binding: val functionName: MethodHandle?
        val funcMatch = Regex("""val\s+(\w+)\s*:\s*MethodHandle\?""").find(line)
        if (funcMatch != null && currentDll != null) {
            dllMap[currentDll]!!.add(funcMatch.groupValues[1])
        }
    }

    // Generate YAML
    val yamlLines = mutableListOf("dll_map:")
    for ((dll, funcs) in dllMap.toSortedMap()) {
        yamlLines.add("  $dll:")
        yamlLines.add("    functions:")
        for (f in funcs.sorted()) {
            yamlLines.add("      - $f")
        }
        yamlLines.add("    structs: []")
        yamlLines.add("    constants: []")
    }

    args.output.writeText(yamlLines.joinToString("\n") + "\n")
    println("Wrote ${args.output.path} (${dllMap.values.sumOf { it.size }} functions, ${dllMap.size} DLLs)")
}

main(args)
```

### Task 9: Create regen-win32-bindings.sh

**Files:**
- Create: `kadre/scripts/regen-win32-bindings.sh`

- [ ] **Step 1: Write the regen script**

```bash
#!/usr/bin/env bash
# Regenerates Win32 FFM bindings from Windows SDK headers via kextract.
# Usage: scripts/regen-win32-bindings.sh [/path/to/kextract]
set -euo pipefail

KEXTRACT="${1:-third_party/kextract/build/kextract/bin/kextract}"
[ -x "$KEXTRACT" ] || { echo "kextract not found at $KEXTRACT"; exit 1; }

REPO="$(cd "$(dirname "$0")/.." && pwd)"
OUT="$REPO/ffi/win32/src/jvmMain/kotlin"

# On Windows, the SDK is at a well-known path. On cross-compile (mingw),
# point --sysroot at the mingw toolchain. Adjust as needed.
SDK_INCLUDE="${SDK_INCLUDE:-C:/Program Files (x86)/Windows Kits/10/Include/10.0.22621.0}"

# Generate a minimal C header that includes only what we need
cat > /tmp/win32-kadre.h << 'CHEADER'
#define WIN32_LEAN_AND_MEAN
#define NOGDI
#define NOMINMAX
#define _WIN32_WINNT 0x0A00

#include <windef.h>
#include <winuser.h>
#include <libloaderapi.h>
#include <errhandlingapi.h>
#include <dwmapi.h>
CHEADER

echo "→ Generating Win32 bindings via kextract..."
"$KEXTRACT" \
    --win32 \
    --dll-map "$REPO/win32-dlls.yaml" \
    -D _WIN32_WINNT=0x0A00 \
    -I "$SDK_INCLUDE/um" \
    -I "$SDK_INCLUDE/shared" \
    -I "$SDK_INCLUDE/ucrt" \
    -t org.graphiks.kadre.ffi.win32 \
    -o "$OUT" \
    /tmp/win32-kadre.h

echo "✓ Done. Generated bindings at $OUT/org/graphiks/kadre/ffi/win32/"
```

### Task 10: Create regen-win32-bindings.yml CI workflow

**Files:**
- Create: `kadre/.github/workflows/regen-win32-bindings.yml`

- [ ] **Step 1: Write the workflow**

```yaml
name: Regenerate Win32 bindings
on:
  workflow_dispatch:
    inputs:
      ref:
        description: 'Branch to regen from (default: master)'
        required: false
        default: 'master'

concurrency:
  group: regen-win32-bindings
  cancel-in-progress: true

jobs:
  regen:
    name: Regenerate Win32 FFM bindings
    runs-on: windows-latest
    permissions:
      contents: write
      pull-requests: write

    steps:
      - name: Checkout
        uses: actions/checkout@v4
        with:
          submodules: recursive
          ref: ${{ inputs.ref || github.ref }}

      - name: Set up JDK 25
        uses: actions/setup-java@v4
        with:
          distribution: 'zulu'
          java-version: '25'
          cache: 'gradle'

      - name: Grant execute permission
        run: |
          chmod +x gradlew
          chmod +x third_party/kextract/gradlew

      - name: Build kextract
        working-directory: third_party/kextract
        run: |
          .\gradlew createKextractImage --no-daemon --stacktrace

      - name: Regenerate Win32 bindings
        shell: bash
        run: |
          scripts/regen-win32-bindings.sh $(pwd)/third_party/kextract/build/kextract/bin/kextract

      - name: Check for changes
        id: changes
        run: |
          if git diff --stat -- 'ffi/win32/' | select -Skip 2 | select-string -Quiet "."; then
            echo "changed=true" >> $env:GITHUB_OUTPUT
          } else {
            echo "changed=false" >> $env:GITHUB_OUTPUT
          }

      - name: Create PR with regenerated bindings
        if: steps.changes.outputs.changed == 'true'
        shell: bash
        run: |
          BRANCH="regen/win32-bindings-$(date +%Y%m%d-%H%M%S)"
          git checkout -b "$BRANCH"
          git config user.name "Kadre Bot"
          git config user.email "bot@graphiks.org"
          git add ffi/win32/
          KEXTRACT_HASH=$(git -C third_party/kextract rev-parse --short HEAD)
          git commit -m "regen: update Win32 FFM bindings from kextract $KEXTRACT_HASH"
          git push origin "$BRANCH"
          gh pr create \
            --title "regen: Win32 FFM bindings" \
            --body "Auto-generated Win32 FFM bindings from kextract \`$KEXTRACT_HASH\`." \
            --label "bindings" \
            --base "${{ inputs.ref || github.ref_name }}"
        env:
          GH_TOKEN: ${{ github.token }}
```
